# SpeakUp AI — English Speaking Coach

Веб-приложение для разговорной практики английского с ИИ через ролевые сценарии. Вы выбираете уровень и
сценарий с конкретной целью (например, «закажите стейк средней прожарки и попросите раздельный счёт»), ИИ играет
свою роль в ситуации, а вы отвечаете текстом или голосом. После каждой реплики приходят 1–3 исправления с
объяснениями на русском, над каждым ответом ИИ показываются новые слова, а в конце — итоги сессии с оценкой цели.

Стек: Next.js 16 (App Router), React 19, TypeScript (strict), CSS Modules, OmniRoute, Cartesia TTS (опционально),
Web Speech API.

## Возможности

- **Сценарии с целью**: Restaurant, Travel, Job Interview, Daily Life и Free Conversation (без цели). ИИ ведёт себя
  как участник ситуации и отмечает, когда цель похоже достигнута.
- **Исправления** (Original / Corrected / Explanation) и практика «Повтори за мной»: прослушать правильную фразу и
  произнести её. Браузер сравнивает **текст распознавания** с целевой фразой, фонетика не оценивается.
- **Новые слова над каждым ответом ИИ**: перевод, пояснение, произношение и кнопка «В словарь». Слова сессии
  копятся без дублей.
- **Перевод по нажатию** на любое слово в ответе ИИ. Сначала используются уже известные данные; запрос к модели
  идёт только для новых слов, и результат кэшируется.
- **💡 Не знаю, что сказать** — 2–3 варианта ответа с переводом. Обычно они приходят вместе с ответом ИИ, без
  отдельного запроса. Вариант подставляется в поле ввода, его можно изменить; сам он не отправляется.
- **Озвучивание**: Cartesia TTS (если настроена) или синтез речи браузера. Скорость 0.7×–1.3× сохраняется между
  визитами, кнопка 🐢 проигрывает ответ на 0.7× без изменения общей настройки.
- **Режим «Только голос»**: говорите → короткая пауза → автоотправка → ответ ИИ озвучивается → микрофон снова
  включается **после** окончания озвучивания. Если речь не распознана, режим останавливается и ждёт нажатия.
- **Итоги сессии**: реплики, новые слова, топ-3 ошибки, совет и оценка цели. Ошибки и слова проверяются на сервере
  по реальной истории диалога.
- **Прогресс в localStorage**: словарь с историей добавления и повторений, серия дней подряд (по локальным датам),
  статистика сессий, скорость голоса. Повторение слов по интервалам 1, 2, 4, 7, 15, 30, 60 дней.
- **Экспорт словаря**: CSV (UTF-8 с BOM, экранирование, защита от формул) и текстовый файл для импорта в Anki.
- **Generate Image → Image Talk**: генерация картинки по выбранной или своей теме, повтор, затем разговор о ней на
  выбранном уровне. Картинка один раз описывается vision-моделью; дальше чат-модель знает её **только по этому
  описанию** (так и написано в интерфейсе), а большие данные изображения не пересылаются с каждым сообщением.
- **Потоковые ответы**: текст реплики ИИ появляется по мере генерации; исправления, слова и подсказки — после
  проверки полного структурированного ответа на сервере.

## Установка и запуск

```bash

```

```bash
cp .env.example .env.local
```

| Переменная | Обязательна | Назначение |
| --- | --- | --- |
| `OMNIROUTE_BASE_URL` | да | OpenAI-совместимый API OmniRoute **с `/v1`**, например `http://localhost:20128/v1` |
| `OMNIROUTE_API_KEY` | зависит от OmniRoute | Ключ из OmniRoute Dashboard → Endpoints. Пусто — запрос без авторизации |
| `OMNIROUTE_MODEL` | да | Основная модель чата с поддержкой `json_schema`, например `grok-cli/grok-4.7` |
| `OMNIROUTE_REASONING_EFFORT` | нет | `reasoning_effort` для моделей с рассуждениями: `low` заметно ускоряет ответы |
| `OMNIROUTE_FAST_MODEL` | нет | Быстрая модель для перевода и подсказок (по умолчанию — основная) |
| `OMNIROUTE_FALLBACK_MODEL` | нет | Проверенная резервная модель; только при тайм-ауте или 5xx основной |
| `OMNIROUTE_IMAGE_MODEL` | нет | Модель `/v1/images/generations`, например `antigravity/gemini-3.1-flash-image` |
| `OMNIROUTE_VISION_MODEL` | нет | Модель с вводом изображений для описания картинки, например `gemini/gemini-3.1-flash-lite` |
| `OMNIROUTE_TTS_MODEL` | нет | Синтез речи через OmniRoute `/v1/audio/speech`, например `elevenlabs/eleven_turbo_v2_5` |
| `OMNIROUTE_TTS_VOICE` | нет | ID голоса провайдера. Для ElevenLabs Free — только стандартные голоса (например `JBFqnCBsd6RMkjVDRZzb`) |
| `CARTESIA_API_KEY` | нет | Ключ Cartesia (`sk_car_…`) с https://play.cartesia.ai/keys. Без него используется голос браузера |
| `CARTESIA_VOICE_ID` | нет | ID голоса из библиотеки Cartesia. Пусто — первый английский голос из `GET /voices?language=en` |
| `CARTESIA_MODEL_ID` | нет | `sonic-3` (по умолчанию), `sonic-3.5`, `sonic-3.6`, `sonic-latest` |
| `CARTESIA_BASE_URL` | нет | Переопределение `https://api.cartesia.ai` (прокси или тестовый стенд) |

Все ключи читаются только на сервере и не попадают в браузер.

## Проверка подключений

OmniRoute:
```bash
curl -X POST http://localhost:3000/api/chat -H "Content-Type: application/json" -d '{"level":"beginner","topic":"travel","messages":[]}'
```

Cartesia — текущий провайдер озвучивания (`cartesia` или `browser`):
```bash
curl http://localhost:3000/api/tts
```

Cartesia — генерация аудио (сохранит mp3):
```bash
curl -X POST http://localhost:3000/api/tts -H "Content-Type: application/json" -d '{"text":"Hello there"}' -o hello.mp3
```

Ошибки возвращаются как `{"error":{"code":"...","message":"..."}}`: 400 — неверный запрос, 413 — слишком большой,
503 — сервис не настроен или недоступен, 502 — ошибка авторизации, модели или формата, 504 — тайм-аут.

## API приложения

| Маршрут | Назначение |
| --- | --- |
| `POST /api/chat` | Реплика ИИ, исправления, слова, подсказки, отметка цели. Ответ — NDJSON-поток: `delta` → `final` / `error` |
| `GET /api/image` | Настроены ли генерация и анализ изображений |
| `POST /api/image` | Генерация (`/v1/images/generations`); возвращает байты изображения, тип проверяется по сигнатуре |
| `POST /api/image/describe` | Однократное описание картинки vision-моделью (до 8 МБ) |
| `POST /api/hints` | Подсказки, если их не было в ответе ИИ |
| `POST /api/translate` | Перевод слова или выражения в контексте |
| `POST /api/summary` | Итоги сессии; ошибки и слова сверяются с историей диалога |
| `GET /api/tts` | Какой провайдер озвучивания доступен |
| `POST /api/tts` | Аудио Cartesia (`POST https://api.cartesia.ai/tts/bytes`, `Cartesia-Version: 2026-08-14`) |

## Голосовые функции: где работают

- **Распознавание речи** (микрофон, «Повтори за мной», «Только голос»): Chrome и Edge на `localhost` или по HTTPS,
  нужен интернет (Chrome распознаёт речь на серверах Google). В Firefox API нет: голосовые кнопки скрываются с
  объяснением, текстовый режим работает.
- **Cartesia**: при заданном `CARTESIA_API_KEY`. Скорость меняется через `HTMLMediaElement.playbackRate` с сохранением
  высоты тона. Если Cartesia недоступна, фраза озвучивается голосом браузера с явной пометкой.
- **Голос браузера**: `speechSynthesis`, скорость через `SpeechSynthesisUtterance.rate`. Качество зависит от
  установленных в ОС английских голосов.

## Озвучивание: порядок выбора

1. `CARTESIA_API_KEY` задан → Cartesia.
2. Иначе задан `OMNIROUTE_TTS_MODEL` → OmniRoute `/v1/audio/speech` (например, ElevenLabs).
3. Иначе — синтез речи браузера.

Активный источник показан в панели «Озвучивание» и под кнопкой «Прослушать». Если серверный TTS не ответил, фраза
звучит голосом браузера с явной пометкой. Ручной тест-план голосовых функций — [docs/VOICE_TEST_PLAN.md](docs/VOICE_TEST_PLAN.md).
