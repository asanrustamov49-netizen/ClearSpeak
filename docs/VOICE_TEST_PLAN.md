# Ручной тест-план голосовых функций (Chrome / Edge)

Распознавание речи нельзя проверить автоматически в среде разработки: браузерная панель Claude блокирует микрофон.
Этот план выполняется вручную в настольном Chrome или Edge.

## Подготовка

1. Запустите OmniRoute и приложение (`npm run dev`), откройте адрес из консоли, например `http://localhost:3000`
   (микрофон работает только на `localhost` или по HTTPS).
2. Подключите микрофон и наушники. Без наушников динамики могут «подсказывать» микрофону ответ ИИ.
3. Откройте DevTools → Console, чтобы видеть ошибки.
4. Начните сессию: Beginner → Restaurant → Start Speaking. Дождитесь первого сообщения ИИ.

Для каждого шага запишите результат: ✅ / ❌ и что произошло.

## 1. Распознавание речи (обычный режим)

| # | Действие | Ожидаемый результат |
|---|---|---|
| 1.1 | Нажмите кнопку микрофона в поле ввода | Браузер спрашивает разрешение на микрофон (при первом запуске) |
| 1.2 | Разрешите и скажите: «I would like a medium steak» | Над полем ввода «Слушаю…», промежуточный текст курсивом |
| 1.3 | Замолчите на 1–2 с | Запись останавливается сама, текст появляется в поле ввода, **не отправляется** |
| 1.4 | Исправьте текст вручную и нажмите Enter | Сообщение отправлено, приходит ответ ИИ и исправления |
| 1.5 | Нажмите микрофон и сразу нажмите его ещё раз (Стоп) | Запись прекращается, индикатор исчезает, ошибок нет |
| 1.6 | Нажмите микрофон и молчите 8–10 с | Сообщение «Речь не распознана…», текстовый ввод работает |

## 2. Отказ в разрешении

| # | Действие | Ожидаемый результат |
|---|---|---|
| 2.1 | Значок замка в адресной строке → Микрофон → «Блокировать», обновите страницу | — |
| 2.2 | Нажмите кнопку микрофона | «Доступ к микрофону запрещён. Разрешите его в настройках сайта…» |
| 2.3 | Отправьте реплику текстом | Диалог работает как обычно |
| 2.4 | Включите «Только голос» и нажмите большой микрофон | То же сообщение об отказе; режим остаётся в состоянии ожидания, повторных попыток нет |
| 2.5 | Верните разрешение «Разрешить», обновите страницу | Микрофон снова работает |

## 3. «Повтори за мной» (практика произношения)

| # | Действие | Ожидаемый результат |
|---|---|---|
| 3.1 | Отправьте фразу с ошибкой: «We want pay separate» | В панели «Исправления» появляется карточка |
| 3.2 | Нажмите «Прослушать» у исправления | Звучит исправленная фраза; подпись источника голоса соответствует панели «Озвучивание» |
| 3.3 | Нажмите «Повторить за мной», произнесите фразу правильно | «Совпадает!», распознанный текст показан |
| 3.4 | Нажмите «Ещё раз», намеренно пропустите слово | «Почти…» и список нераспознанных слов |
| 3.5 | Скажите что-то совсем другое | «Распознано другое…» |
| 3.6 | Проверьте подпись | «Сравнивается текст распознавания речи браузером, а не фонетика» |

## 4. Режим «Только голос»

| # | Действие | Ожидаемый результат |
|---|---|---|
| 4.1 | Включите переключатель «Только голос» | Поле ввода заменено большой кнопкой микрофона, статус «Нажмите на микрофон и говорите» |
| 4.2 | Нажмите микрофон, скажите фразу и замолчите | Статус «Слушаю…» → «Отправляю через секунду…» с полосой обратного отсчёта (~1.5 с) |
| 4.3 | Дождитесь отправки | «ИИ думает…»; сообщение появилось в истории **один раз** |
| 4.4 | Дождитесь ответа | Ответ звучит автоматически, статус «ИИ отвечает…», микрофон **выключен** |
| 4.5 | Дождитесь конца озвучивания | Через ~0.4 с микрофон включается **один раз** («Слушаю…») |
| 4.6 | Промолчите | «Речь не распознана…», режим переходит в ожидание и **больше не включает микрофон сам** |
| 4.7 | Скажите фразу и во время обратного отсчёта нажмите «Отменить» | Ничего не отправлено, текст сброшен |
| 4.8 | Скажите фразу и нажмите «Отправить сейчас» | Отправка без ожидания паузы |
| 4.9 | Во время озвучивания нажмите «Прервать озвучивание» | Звук прекращается; микрофон сам не включается, ждёт нажатия |
| 4.10 | Во время записи нажмите «Вернуться к тексту» | Запись остановлена (индикатор браузера о микрофоне гаснет), снова поле ввода |

### Защита от циклической отправки

| # | Проверка | Ожидаемый результат |
|---|---|---|
| 5.1 | Выполните 4.2–4.5 **без наушников**, громкость средняя | Пока ИИ говорит, микрофон не записывает (кнопка не красная). Голос ИИ не превращается в новое сообщение |
| 5.2 | Посчитайте сообщения «Вы:» после 3 полных циклов | Ровно 3, по одному на каждую вашу фразу |
| 5.3 | Оставьте режим включённым и молчите 1 минуту | Не появляется ни одного нового сообщения, нет повторных запросов в DevTools → Network |

## 6. Озвучивание

| # | Действие | Ожидаемый результат |
|---|---|---|
| 6.1 | Панель «Озвучивание» | Бейдж активного источника: «ElevenLabs через OmniRoute», «Cartesia» или «Голос браузера» |
| 6.2 | «Прослушать» у ответа | Аудио начинается ~через 1 с, подпись под кнопками совпадает с бейджем |
| 6.3 | Скорость 1.30×, «Прослушать» | Заметно быстрее; затем 🐢 — медленно (0.70×), ползунок остаётся на 1.30× |
| 6.4 | Остановите OmniRoute и нажмите «Прослушать» у нового слова | Предупреждение «…Ответ озвучен голосом браузера», подпись «голос браузера» |

Результаты (дата, браузер и версия, ОС, ✅/❌ по пунктам) приложите к задаче.
